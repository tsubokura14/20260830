# ディレクトリ構成

学習実績可視化アプリ（Next.js App Router / 個人開発）のディレクトリ構成と、各ディレクトリ・主要ファイルの役割・責任をまとめる。

## レイヤーで見た責任分担

| レイヤー | ディレクトリ | 責任 |
|---|---|---|
| ルーティング | `src/app/` | URLとページの対応づけ、未ログイン時のリダイレクト |
| プレゼンテーション | `src/components/` | 見た目の描画のみ。DBやビジネスロジックには触れない |
| アプリケーション | `src/actions/` | フォーム入力を受け、バリデーション→DB操作→画面再検証を仲介する |
| バリデーション | `src/schemas/` | Server Actionsに渡ってくる入力データの形式チェック |
| ドメイン/インフラ | `src/lib/` | DB接続・認証・日付計算など、画面に依存しない共通ロジック |
| データ定義 | `drizzle/` | テーブル構造そのものと、その変更履歴(マイグレーション) |
| 品質保証 | `e2e/`・`*.test.ts`・`.github/workflows/` | 単体/結合/E2Eテストと、それを自動で回すCI |

## 対象外のファイル・ディレクトリ

`.claude/`・`.agents/`・`credentials.local.md`・`skills-lock.json`は`.gitignore`に明記されている通り「AIエージェントツール（アプリの動作には無関係）」および「ログイン情報」であり、アプリの実行やアーキテクチャには関与しないためこの図では扱わない。
